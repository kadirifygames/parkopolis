# 🚗 Parkopolis

**Türkiye'yi şehir şehir gezdiğin, renkli bir 3D otopark bulmaca oyunu.**
Arabaları doğru sırayla otoparktan çıkar, tek yönlü yolda çarpıştırma, bir sonraki şehre geç!

## Özellikler
- 🧩 Otomatik üretilen, hepsi çözülebilir leveller
- 🏙️ 6 şehir: İstanbul, Antalya, Kapadokya, Erzurum, Karadeniz, İstanbul Gece
- 🧊 Şehre özel mekanikler: buzlu zemin, renkli kapılar, süreli boss levelleri
- 🚓 Garaj: taksi, polis, ambulans, dolmuş, dondurmacı… ve boya paletleri
- 🎁 Günlük ödül, günlük görevler, sandıklar, Türkiye haritası
- 📅 **Günün Otoparkı:** herkese aynı bulmaca, sonucu arkadaşlarınla paylaş

## Proje
| | |
|---|---|
| Motor | Unity 6 LTS (6000.0.85f1), URP |
| Dil | C# |
| Platform | Android, iOS |
| Paket | `com.kadirify.parkopolis` |

## Açmak için
1. Unity Hub → **Add project from disk** → `ParkingGame` klasörünü seç
2. **Game** sahnesi kendiliğinden açılır → **▶ Play**
3. Üst menüdeki **Kadirify** menüsü: şehre git, test kısayolları, APK/AAB oluşturma

## Klasör yapısı
```
ParkingGame/Assets/_Game/
  Scripts/Core       temel sistemler (kayıt, ses, görevler, garaj)
  Scripts/Gameplay   oyun kuralları (araba, level üretici, çözücü)
  Scripts/Visual     grafikler (araba modelleri, şehirler, efektler)
  Scripts/UI         arayüz ve menüler
  Editor             Unity editör araçları (Kadirify menüsü)
Branding/            logolar
```
